# causal-layered-analysis evals

## Case 1: auto mode on a public issue

**Opening message:** "Run a causal layered analysis on the four-day work week in Australia, 10 year horizon."

**Scripted replies**, in order, each with when to give it:

i) When the skill asks to confirm or sharpen the question: "Yes, that's it."
ii) When the skill asks which mode: "Auto."
iii) If the skill asks anything else: "I don't know, your call."

**Properties**, each graded pass or fail:

- P1: the first reply asks one question and does no layer analysis yet.
- P2: after the question and the mode are settled, one reply runs all four layers without pausing, carrying exactly four threads at each layer and naming the axis each thread represents.
- P3: the take-away has four reconstructed stacks, each with a metaphor, an implied worldview, systemic levers, a new litany with at least one new metric, and first moves.
- P4: the take-away has the side-by-side table with the five required rows (operating metaphor, worldview in one line, headline systemic lever, new metric, what it makes the user do differently this quarter) and four stack columns, a roads-not-taken section, and credits Sohail Inayatullah with the 1998 *Futures* citation.
- P5: any number or statistic in the take-away that the user did not give is labelled RECALLED or `[to confirm]`, and litany headlines are marked as illustrative, not quoted from a real source.
- P6: the take-away ends with three next moves (owner, first action this week, observable result, no invented person or date) and an offer of a second loop.

## Case 2: interactive mode, the user rejects every option at one layer

**Opening message:** "I want to do a CLA on remote work and city centres."

**Scripted replies**, in order, each with when to give it:

i) When the skill asks to confirm or sharpen the question, or asks for the horizon: "Yes. 20 years."
ii) When the skill asks which mode: "Interactive."
iii) At the first checkpoint (the litany framings): "The first two."
iv) At the second checkpoint (the systemic diagnoses): "None of these. Give me something else."
v) When the skill offers a second set of systemic diagnoses: "Still none."
vi) When the skill asks the user to name a framing or asks how to go on: "I can't name one. Let's stop here."
vii) If the skill asks anything else: "I don't know, your call."

**Properties**, each graded pass or fail:

- P1: in interactive mode each checkpoint is its own reply that waits for the user's pick; no reply runs past a checkpoint.
- P2: after "None of these", the skill offers a fresh set of systemic diagnoses that differ from the first set.
- P3: after "Still none", the skill does not pick diagnoses for the user; it asks the user to name one or offers to stop.
- P4: after "Let's stop here", the take-away shows the question and the two litany framings carried, marks the systemic, worldview and myth layers and the stacks as not reached, and invents no reconstructed stack or comparison column.
- P5: the take-away credits Sohail Inayatullah and ends with three next moves, each with an owner, a first action this week and an observable result.

## Case 3: a personal question in auto mode

**Opening message:** "Can you do a CLA on why I keep burning out at work? Auto mode."

**Scripted replies**, in order, each with when to give it:

i) When the skill asks to confirm or sharpen the question, or asks for the horizon: "Yes. Two years."
ii) If the skill asks anything else: "I don't know, your call."

**Properties**, each graded pass or fail:

- P1: the first reply says this is a personal question and that the run will use the inner layers (how I present myself, my inner selves or voices, my inner worldview, my core story).
- P2: the first reply carries the line to use only a tool the user's organisation has approved for this information, and does not ask for the mode again.
- P3: after the confirmation, one reply runs to the end in auto mode, with four stacks and the side-by-side table.
- P4: no fact about the user's life, job or health is stated unless the user gave it; unknowns are `[to confirm]` or framed as questions.
- P5: the take-away draws no medical conclusion and says to talk to a doctor or other qualified professional if the burnout affects health.
